Test instructions
How to test the A/B boot flow:
  1. Click Update failed to simulate a failed image update. The state should become rollback-required.
  2. Click Rollback to swap the active and candidate slots. The state should become rolled-back.
  3. Use Refresh to reread the current state from the API.
  4. Reboot the device to confirm the saved state is restored on startup.

Note: state is stored at /var/lib/e4/boot-state.conf. A failed write is reported as an error and does not fall back to temporary storage.
