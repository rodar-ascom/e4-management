Test instructions
How to test the A/B boot flow:
  1. Set the persistent state path to a writable location such as /var/lib/e4/boot-state.conf.
  2. Click Update failed to simulate a failed image update. The state should become rollback-required.
  3. Click Rollback to swap the active and candidate slots. The state should become rolled-back.
  4. Use Refresh to reread the current state from the API.
  5. Reboot the device to confirm the saved state is restored on startup.

Note: a runtime path like /run is cleared on reboot. The UI allows you to switch to a persistent path for easier validation.
